# Deepfake Patch Detection (Project Work)

This project aims to detect synthetic images (deepfakes) generated by various models (StyleGAN1, StyleGAN2.1, StyleGAN3, StyleGAN XL, Stable Diffusion v1.4, Stable Diffusion 2.1) by distinguishing them from real images (FFHQ Dataset).

The approach is based on extracting *features* (embeddings) using the **OpenCLIP** vision model and subsequently training simple classifiers (MLP, SVM, Linear) to accurately classify what is real and what is generated. The analysis can be performed by evaluating the content globally (using the `CLS` token) or locally (extracting specific `PATCHES`, such as the corners or the center of the image).

## Main Structure and Features

1. **Embeddings Creation**: Passes the images through OpenCLIP and extracts the tensors from the various levels of the ViT network. These are then saved to avoid having to recalculate them in subsequent phases.
2. **Training**: Trains weak and fast classifiers on the various extracted levels. Includes integration with WandB to track *losses* and *accuracies*.
3. **Evaluation (Test)**: Measures the performance of the model. It also supports **Cross-Dataset** testing mode, meaning testing a model trained on images from a certain generator against images produced by a different one, in order to evaluate generalization.
4. **Visualization / Plotting**: Generates graphs on Accuracy, AUC, and creates comparative ROC Curves.
5. **Visual Analysis of Patches**: Generates overlay images to visually show which area of the original image each analyzed patch represents.

## Software Usage and Command Examples

The entire workflow is managed through command-line interaction on the `main.py` file. Below are the instructions grouped by macro-objectives.

### 1. Create Embeddings
The fundamental preliminary operation for the project to work. It scans the images in the dataset and saves the pre-calculated embeddings.
```bash
# To calculate features related to the CLS token
python main.py --create_embeddings --token_mode CLS

# To calculate features related to PATCHES
python main.py --create_embeddings --token_mode PATCHES
```

### 2. Model Training
Starts the training cycle of the classifiers on the extracted datasets.
```bash
python main.py --mode train --dataset stylegan1 --token_mode PATCHES --classificator_model linear --num_epochs 10 --batch_size 32
```
Significant variables:
- `--dataset`: Choose the target fake dataset (`stylegan1`, `sdv1_4`, `stylegan3`, `styleganxl`, `stylegan2`, `sdv2_1`).
- `--classificator_model`: The model to use for training (`linear`, `mlp`, `svm`).
- `--token_mode`: Specifies the spatial context (`CLS` or `PATCHES`).

### 3. Evaluation and Testing
Evaluates an already trained model.

**Standard Interactive Test**
You will be shown a dropdown menu in the terminal asking you which model to test.
```bash
python main.py --mode test --token_mode PATCHES --classificator_model linear
```

**Cross-Dataset Test (Generalization)**
The software will ask you to first select the model with which you trained (to load the weights) and then the dataset on which to perform the test to see how it responds to unseen images ("zero-shot").
```bash
python main.py --mode test --cross_validate --token_mode PATCHES --classificator_model linear
```
*The testing results are automatically saved inside the `csv_results/` folders and raw data in `csv_raw_inferences/`.*

### 4. Graphs and Plots

**Draw Mode (Generates ROC Curves)**
This mode opens a prompt where you can select the various saved inferential results and generate the ROC curve comparisons.
```bash
python main.py --mode draw
```

**Generate Default Graphs for AUC and Accuracy:**
Each new CSV resulting from the tests will be translated into a plot.
```bash
python main.py --plot_results
```

**Targeted Comparison Plots:**
If you want to compare Accuracy trends of different tests (passing the relative CSVs as arguments):
```bash
python main.py --plt_acc_spec csv_results/file1.csv csv_results/file2.csv
```

### 5. Physically Examine Patches (Highlighting on Photo)
This function is purely visual: it superimposes colored rectangles on sample images that you have placed in the subfolders inside `visualization_dataset/` to show where the patches come from (Top Left Corner, Center, etc.).
```bash
python main.py --evidence_patch
```

## Quick Summary of `argparse` Parameters

- `--token_mode` [CLS / PATCHES]: Sets the semantic token usage mode (default: PATCHES).
- `--batch_size`: Size for loader/test (default: 32).
- `--device`: Hardware architecture, `cuda` is recommended where available.
- `--create_embeddings`: Only performs the extraction of pre-computations from CLIP.
- `--mode` [train / test / draw]: Manages the main action of the script to trigger.
- `--num_epochs`: Training epochs.
- `--dataset`: The starting dataset to retrieve fake targets to combine with the implicit real data.
- `--cross_validate`: Enables cross-dataset evaluation.
- `--classificator_model` [mlp / svm / linear]: Architecture on which the estimation is based (default: linear).
- `--plot_results`: Processes the data in the CSV logs producing saved images.
- `--evidence_patch`: Draws visual boundaries on the support figures.
- `--plt_acc_spec`: Loads and compares two or more CSVs to draw new custom plots.
